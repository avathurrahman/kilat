# tests/d1-mock.ts — in-memory D1 mock

## Summary

`tests/d1-mock.ts` wraps `bun:sqlite` with a D1-compatible API (`prepare/bind/first/all/run`) so [[entities/kilat]]'s `db.ts` module works in the test environment without a Wrangler/Miniflare D1 binding. All methods return Promises (D1 is async; bun:sqlite is sync — wrapped in resolved promises).

## Key Takeaways

- `createD1Mock()` returns a `D1Mock` with `prepare()`, `exec()`, and `__db` (internal Database handle)
- `applyMigrations(d1)` reads `migrations/*.sql` and applies them via `d1.exec()`
- `closeD1Mock(d1)` closes the underlying sqlite connection for `afterAll` cleanup
- Bindings typed as `SqlBindings` (string | number | bigint | boolean | null | Uint8Array)
