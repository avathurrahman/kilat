# worker.ts — Cloudflare Workers entry point

## Summary

`src/worker.ts` is the [[concepts/cloudflare-workers|Workers]] entry point for [[entities/kilat]]. It exports `{ fetch }`, which calls `initConfig(env)` + `initDb(env.DB)` per-request, then delegates to `app.fetch(request, env)`. The `Env` interface extends `EnvVars` with `DB: D1Database` and `ASSETS: Fetcher` bindings.

## Key Takeaways

- `initConfig(env)` and `initDb(env.DB)` run per-request — cheap pointer assignments, not cached state
- `manifest.json` imported at module load — run `bun run build` before `wrangler dev` when assets change
- `createApp(assets)` called once at module load — Hono app instance reused across requests
