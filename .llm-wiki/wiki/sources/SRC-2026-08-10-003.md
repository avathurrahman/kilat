# db.ts — D1 async query helpers

## Summary

`src/server/db.ts` is the single D1 database module for [[entities/kilat]]. It uses the `initDb(d1)` pattern: a module-level `d1` variable is set per-request by the Worker fetch handler. All query functions (users, sessions, password resets, uploads, health) are async, using `d1.prepare(sql).bind(...).first/all/run()`.

## Key Takeaways

- `initDb(db: D1Database)` stores the D1 binding in a module-level variable — cheap pointer assignment per-request
- All exports are async query functions (D1 is async — cascades to all route handlers)
- Row types use snake_case → camelCase mapping in SQL (`password_hash AS passwordHash`)
- `PublicUser` type omits `passwordHash` and `googleId` — never leaves the server
- Health check: `pingDb()` = `SELECT 1 AS n`
