# README.md — Kilat project overview

## Summary

The Kilat README documents a full-stack edge starter running entirely on [[entities/kilat|Cloudflare Workers]]. It covers the project philosophy ("predictably fast", "deliberately boring", "one obvious way"), quick start via `bun create kilat`, six template variants (React/Svelte/Vue × vanilla/Tailwind), configuration (env vars, Google OAuth, mail drivers), architecture (file layout, request lifecycle, auth, Inertia protocol, SSR), database migrations, testing, deployment, and styling.

## Key Takeaways

- Six template variants across 3 frameworks (React 19, Svelte 5, Vue 3) and 2 CSS approaches (vanilla/scoped, Tailwind v4) — each on its own branch
- SSR is in-process: `renderToString`/`render` runs inside the Worker bundle — no separate SSR server
- Static assets served via Workers Static Assets binding (`env.ASSETS`), not a custom handler
- Test suite uses `bun test --isolate` (required: each suite sets env in `beforeAll`)
- `bun run build` before `wrangler dev` when assets change — Worker imports `dist/manifest.json` at module load
